Классификатор комментариев: разделение положительных и отрицательных отзывов, авторизация, сохранение запросов и результатов

Цель проекта: приложение, в котором пользователь вводит текст отзыва или комментария и получает результат (положительный или отрицательный), а также видит историю своих запросов после входа в систему. В лабараторной №1 нужно реализовать только интерфейс на демонстрационных данных без настоящего сервера и базы данных.

Реализовано в проекте:
1.	Проект создан на React + TypeScript при помощи сборщика Vite.
2.	В качестве библиотеки UI-компонентов используется Ant Design (antd). Она даёт готовые кнопки, поля ввода, таблицы, уведомления с единым оформлением.
3.	Реализована клиентская маршрутизация (react-router-dom) между четырьмя экранами: «Вход», «Регистрация», «Классификатор» и «История».
4.	На главном экране пользователь вводит текст комментария и получает результат - метку «положительный» или «отрицательный». Сейчас эта классификация выполняется демонстрационной функцией в браузере по ключевым словам, а не настоящей моделью.
5.	Экран «История» показывает заранее подготовленный список запросов и результатов.
6.	Экраны «Вход» и «Регистрация» содержат формы с проверкой заполнения полей, но пока не обращаются к серверу.

Проект использует внешние библиотеки (React, Ant Design, react-router и тд), перечисленные в файле package.json. Сами файлы этих библиотек в архиве не передаются — они скачиваются автоматически командой npm install и складываются в папку node_modules. Чтобы запустить приложение, используется команда npm run dev. После этого показывается адрес, на которомможно просмотреть приложение локально (обычно это http://localhost:5173/)
